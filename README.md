## Color palette

| Role | Hex | Where used |
|---|---|---|
| Wordmark on light background | `#1D2125` | Letter fill in `*-light.svg` |
| Symbol — primary | `#C24E36` | Inner mark in `*-light.svg` |
| Symbol — accent stroke | `#EC6C50` | Hook stroke in subtitle variants |
| Wordmark on dark background | `#D8B98C` | Letter fill in `*-dark.svg` |
| Symbol on dark background | `#FFFFFF` | Inner mark in `*-dark.svg` |

## Picking the right variant

- **Default** → `bizkithub-logo-light.svg`. Use on any light or neutral background.
- **Dark UI** → `bizkithub-logo-dark.svg`. Use on backgrounds darker than `#555`.
- **Auto dark-mode in Markdown / HTML** → wrap with `<picture>`:

  ```html
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="bizkithub-logo-dark.svg">
    <img src="bizkithub-logo-light.svg" alt="BizKitHub" width="200">
  </picture>
  ```

- **Favicon / small icon** → `bizkithub-symbol-small.svg` or `favicon.svg`.
- **Hero / about page / splash** → the subtitle variant for brand recognition.
- **In-app header** → recommended size `150×32 px`; use the primary logo.

## Usage policy

The BizKitHub brand (name, logo, symbol, color palette) is a trademark of BizKitHub. Partners, press, and integrators may use these assets to refer to BizKitHub provided that:

- The mark is not altered (no stretching, re-coloring, re-stacking, or added effects).
- Clear space of at least the height of the symbol is kept around the logo.
- The logo is not implied to endorse a third-party product without a prior written agreement.

For commercial co-branding or any derivative use, contact <https://bizkithub.com>.
